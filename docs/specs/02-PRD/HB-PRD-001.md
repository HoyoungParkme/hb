# PRD — 제품 요구

## 1. 목표

#### G1 손으로 항목을 붙이는 시간을 없앤다

한 달치 거래(200~300건)를 넣고 사람이 손댈 것은 「미분류」로 남은 새 가맹점뿐이어야 한다. 근거: [[HB-RFQ-001#Q2]] · [[HB-RFQ-001#Q3]]

#### G2 내 컴퓨터 밖으로 아무것도 나가지 않는다

거래 내역·규칙·요약 전부 로컬 파일에만 산다. 근거: [[HB-RFQ-001#Q5]]

## 2. 비목표

#### N1 은행·카드사 API 연동

파일을 내려받아 넣는 것으로 충분하다. 자동 수집(스크래핑·오픈뱅킹)은 하지 않는다. 근거: [[HB-RFQ-001#Q1]]의 「파일을 그대로 넣는다」

#### N2 다중 사용자·공유·클라우드 동기화

사용자는 한 명이다. 근거: [[HB-RFQ-001#Q5]]

#### N3 기계학습 기반 분류

같은 가맹점은 항상 같은 항목이라는 요구([[HB-RFQ-001#Q2]])에는 규칙표가 정확하고 설명 가능하다. 통계 모델은 첫 버전 범위 밖이다.

#### N4 예산·목표 관리, 자산 관리

지출 분류와 월 요약까지만 한다.

## 3. 요구사항

#### R1 CSV 가져오기 — 기관별 형식 자동 인식

근거: [[HB-RFQ-001#Q1]]

은행 1곳·카드 2곳의 CSV를 각각의 「가져오기 프로파일」로 읽는다. 프로파일은 헤더 행의 컬럼 이름으로 자동 판별한다. 인코딩(UTF-8/CP949)과 날짜 표기(`2026-09-01`, `2026.09.01`, `20260901`)를 프로파일이 흡수한다.

- [ ] 세 기관의 샘플 파일이 각각 프로파일 판별 후 오류 없이 읽힌다
- [ ] 판별 실패 시 「어느 기관 파일인지 모르겠다」는 메시지와 함께 헤더 행을 보여 주고 거래를 하나도 저장하지 않는다
- [ ] 한 파일 300건 가져오기가 2초 안에 끝난다

#### R2 중복 거래 배제

근거: [[HB-RFQ-001#Q6]]

거래마다 `(기관, 일시, 금액, 원문 적요)`로 지문(fingerprint)을 만들고, 이미 있는 지문은 저장하지 않는다. 가져오기 결과에 「새로 들어온 N건 · 건너뛴 M건」을 보인다.

- [ ] 같은 파일을 두 번 넣으면 두 번째는 새로 들어온 건이 0이다
- [ ] 같은 날 같은 가맹점에서 같은 금액을 두 번 결제한 경우(원문 적요가 다름)는 둘 다 들어온다

#### R3 규칙표에 따른 자동 분류

근거: [[HB-RFQ-001#Q2]]

가맹점명(정규화한 적요)과 항목을 짝지은 「분류 규칙」표를 두고, 가져온 거래마다 규칙을 찾아 항목을 붙인다. 규칙은 정확 일치가 먼저, 다음이 포함(부분 문자열) 일치다. 규칙이 없으면 「미분류」다. 기본 항목은 식비·교통·주거·통신·의료·문화·쇼핑·이체·수입·기타·미분류 11개다.

- [ ] 규칙이 있는 가맹점의 거래는 100% 그 항목이 붙는다
- [ ] 규칙이 없는 거래는 미분류로 남는다 — 추측으로 채우지 않는다
- [ ] 정확 일치 규칙과 포함 규칙이 둘 다 맞으면 정확 일치가 이긴다

#### R4 항목 수정과 규칙 학습

근거: [[HB-RFQ-001#Q3]]

사용자가 거래의 항목을 바꾸면 그 거래가 바뀌고, 같은 가맹점 규칙이 만들어지거나 갱신된다. 규칙이 바뀌면 같은 가맹점의 기존 미분류 거래도 함께 바뀐다. 이미 사람이 확정한 거래는 규칙 변경으로 덮어쓰지 않는다.

- [ ] 미분류 거래 하나에 항목을 붙이면 같은 가맹점의 다른 미분류 거래가 같은 항목으로 바뀐다
- [ ] 다음 달 파일에서 같은 가맹점은 자동으로 그 항목이 붙는다
- [ ] 사람이 직접 고친 거래는 「확정」 표시가 남고 이후 규칙 변경에 영향받지 않는다

#### R5 월 요약

근거: [[HB-RFQ-001#Q4]]

월을 고르면 항목별 합계(지출·수입 구분), 항목별 거래 목록, 미분류 건수를 보인다. 전월 대비 항목별 증감은 있으면 보인다.

- [ ] 항목별 합계의 총합이 그 달 거래 금액 총합과 일치한다
- [ ] 미분류 건수가 0이 아니면 요약 상단에 눈에 띄게 보인다
- [ ] 전월 데이터가 없으면 증감 칸은 빈칸이다(0으로 보이지 않는다)

#### R6 로컬 단독 실행

근거: [[HB-RFQ-001#Q5]]

네트워크 호출이 없다. 데이터는 사용자 홈 아래 파일 하나(SQLite)에 산다. 명령 하나로 켜고 브라우저로 연다.

- [ ] 네트워크를 끊은 상태에서 R1~R5가 전부 동작한다
- [ ] 데이터 파일 하나를 복사하면 다른 컴퓨터에서 그대로 열린다

#### R7 취소 거래 처리

근거: [[HB-RFQ-001#Q1]] · [[HB-RFQ-001#Q6]] 의 미정 항목

카드사 파일의 「취소」 행은 금액 부호를 뒤집은 거래로 들어오고, 원 거래와 같은 항목을 받는다. 상계(원 거래 삭제)는 하지 않는다.

- [ ] 취소 행이 음수 금액으로 들어와 월 합계에서 빠진다

## 4. 성공지표

| 지표 | 목표 | 재는 법 |
|---|---|---|
| 한 달치 처리에 사람이 쓰는 시간 | 10분 이내 | 파일 넣기부터 미분류 0건까지 |
| 둘째 달부터 미분류 비율 | 10% 이하 | 미분류 건수 / 전체 건수 |
| 외부 네트워크 호출 | 0회 | 통합 테스트에서 소켓 차단 |
