# USECASE (Cockburn)

## 0. 이 문서의 형식

Cockburn 완전 서술형. 사용자 목표 수준은 `UC-H{n}`(사람이 주 액터), 시스템이 스스로 하는 것은 `UC-S{n}`. 이 도구에는 에이전트·외부 시스템 액터가 없다.

## 1. 액터

| 액터 | 종류 | 설명 |
|---|---|---|
| 사용자 | 사람 | [[HB-SCN-001#P1]]. 파일을 넣고, 미분류를 정리하고, 요약을 본다 |
| 분류기 | 시스템 | 규칙표로 거래에 항목을 붙이는 내부 구성요소 |

## 2. 사용자 목표 수준 유스케이스

#### UC-H1 거래 파일 가져오기

| 항목 | 내용 |
|---|---|
| 범위 | 가계부 자동 분류 도구 |
| 수준 | 사용자 목표 |
| 주 액터 | 사용자 |
| 이해관계자와 관심사 | 사용자 — 파일을 손대지 않고 넣고 싶다, 중복이 생기면 안 된다 |
| 사전조건 | 도구가 켜져 있고 브라우저로 열려 있다 |
| 최소 보장 | 실패하면 거래가 하나도 저장되지 않는다 |
| 성공 보장 | 새 거래가 저장되고 각각 항목이 붙거나 미분류로 남는다. 결과 건수가 보인다 |
| 트리거 | 사용자가 CSV 파일을 화면에 놓는다 |
| 패키지 | 가져오기 |
| 포함(include) | [[HB-UC-001#UC-S1]] |
| 확장점(extension point) | — |
| 일반화 | — |

**기본 흐름**
1. 사용자가 CSV 파일을 놓는다.
2. 시스템이 인코딩을 판별해 헤더 행을 읽고, 가져오기 프로파일을 고른다.
3. 시스템이 행마다 거래(일시·금액·원문 적요·기관)를 만든다.
4. 시스템이 거래마다 지문을 계산해 이미 있는 것을 건너뛴다.
5. 시스템이 새 거래마다 분류기를 불러 항목을 붙인다([[HB-UC-001#UC-S1]]).
6. 시스템이 새 거래를 저장하고 「형식 · 새로 들어온 N · 건너뛴 M · 미분류 K」를 보인다.

**확장**
- **2a. 헤더가 어느 프로파일과도 맞지 않는다**
  - 2a1. 시스템이 「어느 기관 파일인지 모르겠다」와 헤더 행을 보이고 끝낸다. 저장 없음.
- **3a. 어떤 행의 날짜·금액을 읽을 수 없다**
  - 3a1. 시스템이 그 행 번호와 내용을 모아 두고 계속 진행한다.
  - 3a2. 6에서 「읽지 못한 행 J건」을 함께 보인다.
- **3b. 취소 행이다**
  - 3b1. 금액 부호를 뒤집어 거래로 만든다. 계속.
- **4a. 모든 거래가 이미 있다**
  - 4a1. 「새로 들어온 0 · 건너뛴 M」을 보이고 끝낸다.

#### UC-H2 미분류 거래에 항목 붙이기

| 항목 | 내용 |
|---|---|
| 범위 | 가계부 자동 분류 도구 |
| 수준 | 사용자 목표 |
| 주 액터 | 사용자 |
| 이해관계자와 관심사 | 사용자 — 한 번 고른 것은 다시 묻지 않기를 바란다 |
| 사전조건 | 미분류 거래가 1건 이상 있다 |
| 최소 보장 | 선택하지 않은 거래는 바뀌지 않는다 |
| 성공 보장 | 그 가맹점 규칙이 생기고, 같은 가맹점의 미확정 거래가 전부 그 항목이 된다 |
| 트리거 | 사용자가 미분류 목록을 연다 |
| 패키지 | 분류 |
| 포함(include) | — |
| 확장점(extension point) | — |
| 일반화 | — |

**기본 흐름**
1. 시스템이 미분류 거래를 정규화한 가맹점명으로 묶어 보인다(묶음마다 건수·합계).
2. 사용자가 묶음 하나에 항목을 고른다.
3. 시스템이 규칙 「가맹점 → 항목」을 만든다(있으면 갱신).
4. 시스템이 같은 가맹점의 미확정 거래를 전부 그 항목으로 바꾼다.
5. 시스템이 묶음을 목록에서 지우고 남은 미분류 건수를 갱신한다.

**확장**
- **2a. 사용자가 「기타」를 고른다**
  - 2a1. 규칙은 기타로 만들어진다. 미분류와 기타는 다르다 — 기타는 사람이 판단한 것이다.
- **3a. 같은 가맹점에 정확 일치 규칙이 이미 있다**
  - 3a1. 규칙의 항목을 새 항목으로 바꾼다. 4로.

#### UC-H3 거래 항목 고치기

| 항목 | 내용 |
|---|---|
| 범위 | 가계부 자동 분류 도구 |
| 수준 | 사용자 목표 |
| 주 액터 | 사용자 |
| 이해관계자와 관심사 | 사용자 — 예외 한 건을 고치는 것과 규칙을 바꾸는 것을 구분하고 싶다 |
| 사전조건 | 항목이 붙은 거래가 있다 |
| 최소 보장 | 확정된 다른 거래는 바뀌지 않는다 |
| 성공 보장 | 「이 건만」이면 그 거래만 바뀌고 확정된다. 「이 가맹점 전부」면 규칙과 미확정 거래가 바뀐다 |
| 트리거 | 사용자가 거래 하나의 항목을 바꾼다 |
| 패키지 | 분류 |
| 포함(include) | — |
| 확장점(extension point) | — |
| 일반화 | — |

**기본 흐름**
1. 사용자가 거래 하나를 열고 다른 항목을 고른다.
2. 시스템이 「이 건만 / 이 가맹점 전부」를 묻는다.
3. 사용자가 「이 건만」을 고른다.
4. 시스템이 그 거래의 항목을 바꾸고 확정 표시를 붙인다. 규칙은 그대로다.

**확장**
- **3a. 사용자가 「이 가맹점 전부」를 고른다**
  - 3a1. 시스템이 규칙을 새 항목으로 바꾼다(없으면 만든다).
  - 3a2. 시스템이 같은 가맹점의 미확정 거래를 전부 새 항목으로 바꾼다. 확정 거래는 건드리지 않는다.

**연관**: [[HB-PRD-001#R4]] · [[HB-SCN-001#S3]]

#### UC-H4 월 요약 보기

| 항목 | 내용 |
|---|---|
| 범위 | 가계부 자동 분류 도구 |
| 수준 | 사용자 목표 |
| 주 액터 | 사용자 |
| 이해관계자와 관심사 | 사용자 — 이번 달 어디에 얼마 썼는지, 지난달과 뭐가 달라졌는지 |
| 사전조건 | 그 달 거래가 1건 이상 있다 |
| 최소 보장 | 합계는 항상 거래 목록과 일치한다 |
| 성공 보장 | 항목별 합계·목록·미분류 건수·전월 증감이 보인다 |
| 트리거 | 사용자가 월을 고른다 |
| 패키지 | 요약 |
| 포함(include) | — |
| 확장점(extension point) | — |
| 일반화 | — |

**기본 흐름**
1. 사용자가 월을 고른다.
2. 시스템이 그 달 거래를 항목별로 합산한다(지출·수입 구분).
3. 시스템이 전월 합계가 있으면 항목별 증감을 계산한다.
4. 시스템이 미분류 건수를 상단에, 항목별 합계와 증감을 표로 보인다.
5. 사용자가 항목 하나를 누르면 그 항목의 거래 목록이 펼쳐진다.

**확장**
- **3a. 전월 거래가 없다**
  - 3a1. 증감 칸을 빈칸으로 둔다.
- **4a. 미분류가 0건이다**
  - 4a1. 미분류 표시를 숨긴다.

## 3. 하위기능 수준 유스케이스

#### UC-S1 거래 하나 분류하기

| 항목 | 내용 |
|---|---|
| 범위 | 분류기 |
| 수준 | 하위기능 |
| 주 액터 | 분류기 |
| 이해관계자와 관심사 | 사용자 — 같은 가맹점은 항상 같은 항목 |
| 사전조건 | 거래에 원문 적요가 있다 |
| 최소 보장 | 규칙이 없으면 미분류다. 추측하지 않는다 |
| 성공 보장 | 규칙에 따른 항목이 붙는다 |
| 트리거 | 가져오기가 새 거래를 넘긴다 |
| 패키지 | 분류 |
| 포함(include) | — |
| 확장점(extension point) | — |
| 일반화 | — |

**기본 흐름**
1. 분류기가 원문 적요를 정규화한다(공백·괄호·지점명·숫자 꼬리 제거, 소문자화).
2. 분류기가 정규화한 가맹점명과 정확히 일치하는 규칙을 찾는다. 있으면 그 항목. 끝.
3. 없으면 포함 규칙(규칙 문자열이 가맹점명에 들어 있는 것)을 찾는다. 여럿이면 가장 긴 것. 있으면 그 항목. 끝.
4. 없으면 미분류.

**확장**
- **1a. 정규화 결과가 빈 문자열이다**
  - 1a1. 원문 적요 그대로를 가맹점명으로 쓴다.
