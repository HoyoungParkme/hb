# 사용자 시나리오

## 0. 범위와 전제

- 사용자는 한 명, 자기 노트북에서 브라우저로 쓴다([[HB-PRD-001#R6]]).
- 한 달에 한두 번, 은행·카드 CSV를 내려받아 넣고 미분류만 정리한다.
- 첫 달(규칙이 하나도 없을 때)과 둘째 달 이후(규칙이 쌓였을 때)는 흐름이 다르므로 둘 다 적는다.

## 1. 페르소나

#### P1 지훈 — 혼자 쓰는 개발자

| 항목 | 내용 |
|---|---|
| 누구 | 30대 개발자, 월급 계좌 1개·카드 2장 |
| 습관 | 월초에 지난달 내역을 내려받아 한 번에 정리한다. 매일은 안 본다 |
| 바라는 것 | 「반복되는 건 알아서, 새 것만 물어봐」 |
| 싫어하는 것 | 계정 만들기, 외부 서비스에 거래 내역 올리기, 설치 절차 |

## 2. 시나리오

#### S1 첫 달 — 파일 넣고 미분류 정리하기

**주체**: P1
**상황**: 처음 도구를 켰다. 규칙이 하나도 없다. 은행 CSV 1개, 카드 CSV 2개를 내려받아 두었다.

1. 지훈이 도구를 켜고 브라우저로 연다. 빈 화면에 「파일을 넣으세요」가 보인다.
2. 은행 CSV를 끌어다 놓는다. 「은행 A 형식 · 새로 들어온 84건 · 건너뛴 0건 · 미분류 84건」이 보인다.
3. 카드 CSV 둘을 차례로 넣는다. 각각 「카드 B 형식 · 150건」, 「카드 C 형식 · 41건」.
4. 미분류 목록(275건)을 연다. 가맹점명으로 묶여 있어 실제 줄은 60개 남짓이다.
5. 「스타벅스」 묶음에 식비를 고른다. 묶음 안 12건이 한꺼번에 식비가 되고 규칙 「스타벅스 → 식비」가 생긴다.
6. 60개 묶음을 10분 안에 다 고른다. 미분류 0건.
7. 9월 요약을 연다. 항목별 합계와 목록이 보인다. 전월 칸은 빈칸이다.

**변형 — 형식을 못 알아본 파일**: 2에서 헤더가 알 수 없는 파일이면 「어느 기관 파일인지 모르겠다」와 헤더 행이 보이고 아무것도 저장되지 않는다([[HB-PRD-001#R1]]).

**성공 조건**: 세 파일 275건이 다 들어오고, 규칙 60개 안팎이 생기고, 미분류 0건으로 9월 요약이 보인다.
**연관 요구사항**: [[HB-PRD-001#R1]] · [[HB-PRD-001#R3]] · [[HB-PRD-001#R4]] · [[HB-PRD-001#R5]]

#### S2 둘째 달 — 새 가맹점만 물어본다

**주체**: P1
**상황**: 규칙 60개가 있다. 10월 파일 셋을 내려받았다.

1. 파일 셋을 넣는다. 「새로 들어온 262건 · 미분류 9건」.
2. 미분류 9건(가맹점 7개)을 연다. 처음 간 식당·병원 등이다.
3. 7개 묶음에 항목을 고른다. 2분.
4. 10월 요약을 연다. 전월 대비 증감이 항목마다 보인다. 「의료」가 +48,000원으로 눈에 띈다.
5. 의료 항목을 눌러 거래 목록을 보고 납득한다.

**변형 — 지난달 파일을 또 넣었다**: 1에서 9월 카드 파일을 실수로 다시 넣으면 「새로 들어온 0건 · 건너뛴 150건」이 보이고 아무것도 바뀌지 않는다([[HB-PRD-001#R2]]).

**성공 조건**: 사람이 손댄 것은 미분류 9건뿐이고, 요약에 전월 증감이 보인다.
**연관 요구사항**: [[HB-PRD-001#R2]] · [[HB-PRD-001#R3]] · [[HB-PRD-001#R5]]

#### S3 잘못 붙은 항목 고치기

**주체**: P1
**상황**: 「쿠팡」이 쇼핑으로 붙었는데 이번 건은 생수 정기배송이라 식비로 두고 싶다. 규칙은 그대로 쇼핑이어야 한다.

1. 10월 요약의 쇼핑 항목에서 쿠팡 거래 하나를 연다.
2. 항목을 식비로 바꾸며 「이 건만」을 고른다. 거래에 「확정」 표시가 붙는다.
3. 규칙 「쿠팡 → 쇼핑」은 그대로다. 다음 달 쿠팡은 여전히 쇼핑이다.

**변형 — 규칙째 바꾸기**: 2에서 「이 가맹점 전부」를 고르면 규칙이 식비로 바뀌고, 확정되지 않은 쿠팡 거래가 전부 식비가 된다. 확정된 거래는 그대로다([[HB-PRD-001#R4]]).

**성공 조건**: 「이 건만」은 거래 하나만, 「이 가맹점 전부」는 규칙과 미확정 거래를 바꾼다.
**연관 요구사항**: [[HB-PRD-001#R4]]

#### S4 카드 취소 건이 섞여 있다

**주체**: P1
**상황**: 카드 B 파일에 10/3 결제 35,000원과 10/4 취소 35,000원이 따로 들어 있다.

1. 파일을 넣는다. 취소 행은 -35,000원 거래로 들어온다.
2. 원 거래가 문화라면 취소 거래도 문화가 된다.
3. 10월 요약의 문화 합계에서 둘이 상쇄된다.

**성공 조건**: 취소 건이 합계를 부풀리지 않고, 목록에는 두 줄이 다 남는다.
**연관 요구사항**: [[HB-PRD-001#R7]]
